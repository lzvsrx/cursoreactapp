# Desafio DIO — Main Hooks

Projeto recriado a partir de https://github.com/digitalinnovationone/trilha-react-native-main-hooks.

Entrega: três demonstrações interativas de `useState`, `useRef` e `useReducer`, com React Native, Expo SDK 58 e TypeScript estrito.

- Estado: quantidade e preço de um pedido, com limites e atualização funcional.
- Referência: foco no campo e limpeza de texto controlado.
- Reducer: escrever, limpar e desfazer com transições puras e histórico limitado.

O reducer não contém referências de componentes nem executa `setNativeProps`. O texto está no estado React; o foco ocorre nos eventos da interface.

Consulte o [README](README.md) para instalação, versões, testes e roteiro manual. Código principal em `App.tsx`; regras do editor em `src/state/editor.ts`.
